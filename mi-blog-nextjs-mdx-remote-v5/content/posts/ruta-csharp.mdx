# Nivel 2 — LINQ

Aquí pondría **muchísimo énfasis**.

Debes poder resolver sin pensar demasiado cosas como:

```csharp
var customers = customers
    .Where(c => c.IsActive)
    .OrderBy(c => c.Name)
    .Select(c => new
    {
        c.Id,
        c.Name
    })
    .ToList();
```

Y entender perfectamente:

```text
Where
Select
SelectMany
OrderBy
ThenBy
GroupBy
Join
Any
All
Contains
First
FirstOrDefault
Single
SingleOrDefault
Count
Sum
Average
Min
Max
Distinct
ToList
ToArray
ToDictionary
```

**LINQ es extremadamente importante para una prueba de C#.**
